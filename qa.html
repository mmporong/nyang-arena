Nyang Arena 제출 전 2분 QA

자동 테스트가 좌표·경계·오디오 스케줄·배포 응답을 먼저 검사했다. 사람은 아래 두 가지만 판정한다. 이 페이지는 로컬 Vite 개발 서버에서만 열리며 프로덕션 빌드에는 포함되지 않는다.

1. 실제 Canvas 아이콘 17종

왼쪽은 실사용 최솟값 6.3px, 오른쪽은 일반 크기 32px다. 같은 의미끼리 뭉개지거나 정사각형 밖으로 잘린 아이콘이 없는지만 본다.

2. 실제 Web Audio 보스 신호

첫 버튼을 누르고 눈을 감는다. 보스 BGM 위에서 짧은 두 번 → 낮고 긴 한 번 → 맑고 긴 울림 순서가 구분되면 통과다.

배포본 900×320 안전 확인

아래는 현재 GitHub Pages 배포본을 정확히 900×320으로 띄운 화면이다. 지도 칸 하나를 고른 뒤 상점 카드와 직업 카운터에 잘림·겹침이 없는지만 본다. 별도 창이 필요하면 링크를 연다.
