# 냥 아레나 (Nyang Arena)

브라우저에서 바로 돌아가는 **픽셀 고양이 오토배틀러**.
3×3 보드에 고양이를 배치하고, 자동 전투를 관전하고, 몇 웨이브까지 버티는지 겨룬다.

**매 판의 규칙이 다르다.** 시너지 세 개는 LLM이 생성한 풀에서 뽑히고,
어떤 조합을 세우느냐에 따라 켜지는 시너지가 달라진다.

## 플레이

1. 우리 편 3×3 보드에 고양이를 **드래그해서 배치**한다 (마우스·터치 모두 가능)
2. **전투 시작** — 고양이들이 직접 걸어나가 싸운다. 근접은 붙으러 달려가고, 원거리는 뒤에서 쏜다
3. 이기면 생선을 받고 **영입하거나 강화**한다
4. 웨이브마다 적이 강해진다. 전멸하면 도달 웨이브가 기록된다

고양이마다 **근**(근접) / **원**(원거리) 뱃지가 붙는다. 근접은 사거리가 짧아 적에게
걸어가야 하고 체력이 높다. 원거리는 제자리에서 쏘고 체력이 낮다. 그래서 앞줄에
근접, 뒷줄에 원거리를 두는 배치가 생긴다.

시너지는 화면 아래 띠에 표시되고, 조건을 만족하면 금색으로 켜진다.

| 시너지 조건 | 뜻 |
|---|---|
| 같은 색 3 | 같은 털색 고양이가 3마리 이상 |
| 같은 품종 2 | 같은 품종이 2마리 이상 |
| 전부 다른 색 5 | 5마리 이상이고 색이 전부 다름 |

## AI를 어디에 썼나

이 게임에서 AI는 **게임 규칙을 만드는 자리**에 있다. 대사나 장식이 아니다.

```
개발 시간                              배포 후 런타임
─────────────────────────────         ──────────────────────
LLM이 시너지 규칙 후보 생성            data.json에서 3개 추출
        ↓                              (네트워크 호출 0건)
검증기: 화이트리스트 통과 검사
        ↓  범위 밖 수치는 클램프
        ↓  허용되지 않은 트리거·효과는 폐기
src/data/synergies.json 로 커밋
```

핵심은 생성이 아니라 **압축**이다. LLM 출력을 그대로 실행하면 게임이 깨지거나
밸런스가 무너진다. 그래서 출력을 좁은 DSL로 강제하고, 통과하지 못한 것은 버리고,
통과한 값도 게임이 감당하는 범위로 누른다. 전부 버려져도 프리셋으로 폴백해서
게임은 반드시 돈다.

검증기가 실제로 막는지는 테스트로 증명한다:

```
$ npm test
적대 입력 11개 → 폐기 8개, 통과 3개
  quad_color     허용되지 않은 trigger: same_color_4
  finisher       허용되지 않은 effect.key: instant_kill
  9bad_id        id 형식 위반
  dup_id         id 중복: dup_id
  stringy        effect.value가 유한한 수가 아님
  ...
통과했지만 값이 눌린 항목:
  overshoot      atk_mul=1.6   (원본 9.9 → 상한으로 클램프)
  tag_soup       name="태그scriptalert(1)"  (꺾쇠 제거)
```

## 밸런스를 어떻게 잡았나

눈대중으로 맞추지 않았다. 게임 로직을 브라우저 없이 그대로 돌리는 하네스로
도달 웨이브 분포를 측정하고 튜닝했다.

```
$ npm run sim
런 300회 (정책: 살 수 있으면 가장 비싼 것 구매, 재배치 없음)
  최소 8  p25 10  중앙값 10  p75 10  최대 15
```

이 과정에서 실제로 잡은 결함:

- 레벨 성장이 선형이라 웨이브 2에서 전멸 → 지수 성장으로 교정
- 강화 비용이 선형이라 후반에 무한히 강해짐(12%가 상한 도달) → 비용도 지수로
- 보드가 꽉 찼을 때 영입 카드가 남아 무한 재시도 → 오퍼에서 제거
- 타임아웃을 체력 비율로 판정해 런이 안 끝남 → 타임아웃은 패배로

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 타입체크 + 프로덕션 빌드
npm test           # 검증기 적대 테스트
npm run sim        # 밸런스 시뮬레이션
```

런타임 의존성 0개. 빌드 산출물은 JS 약 25 kB(gzip 10 kB) + 스프라이트.

## 기술

TypeScript · Vite · Canvas 2D. 엔진·프레임워크 없음.
아트는 자체 제작 픽셀 고양이 20종 × 6포즈 시트를 `npm run slice`로 잘라 쓴다
(T1 빌드는 8종 사용).
