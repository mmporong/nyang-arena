# 트랙 A 시각 검증 증거

2026-08-23 로컬 Vite 빌드(`http://127.0.0.1:4173/?debug=1`)를 Edge CDP로
1440×900 캡처했다. 키 입력은 공개된 디버그 상태를 읽어 실제 게임 루프에 넣었고,
런타임 상태나 전투 수치는 직접 바꾸지 않았다.

| 파일 | 검증 장면 | 판정 |
|---|---|---|
| `09-boss-arrival.png` | 스테이지 보스 전투 시작 | HUD·버튼은 고정되고 판 내부의 보스만 사건으로 커진다 |
| `10-boss-danger.png` | 보스 원형 위험 예고 | 분홍 해칭과 외곽 도화선이 직업색·배경보다 먼저 읽히고 일반 피해 숫자는 뒤로 물러난다 |
| `11-boss-gather-perimeter.png` | 보스 집결 예고 | 청록 동심원과 외곽 도화선이 중앙 고양이를 가리지 않고 남은 시간을 말한다 |
| `12-boss-vulnerable.png` | 보스 취약 창 | 금빛 고리와 버튼이 같은 행동 창을 가리키며 다른 고채도 신호와 섞이지 않는다 |
| `13-reduced-motion-danger.png` | `prefers-reduced-motion: reduce` 위험 예고 | 맥동·비행·흔들림 없이 같은 위험 기하와 입력 정보가 유지된다 |

스크린샷 한 장으로 정지 여부를 증명할 수는 없으므로 모션 축소의 동작 계약은
`src/game/render.ts`의 미디어 쿼리 분기와 타입체크·브라우저 에뮬레이션
`matchMedia(...).matches === true` 결과를 함께 근거로 삼는다.
