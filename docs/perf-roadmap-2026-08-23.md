### 1-5. 적재

2026-08-23 측정 당시 첫 로드 전송량 ≈ **370 KB**: JS 142.5 KB(gzip **50.6 KB**) + index.html 2.3 KB(gzip 1.2) + 스프라이트 PNG 186장
**180.5 KB** + 당시 아이콘 17장 약 35 KB. BGM은 지연 로드(ogg 452 KB / mp3 616 KB 중 한 벌만) — 이미 잘 되어 있다.
현재 구성에서는 출처를 검증한 PNG 13장 33.6 KB만 남기고, 논리 아이콘 4종을 Canvas 패스로 대체했다. 최신 번들 값은 `docs/generated/metrics-current.md`를 기준으로 한다.
**문제는 용량이 아니라 개수와 메모리다.** 스프라이트 186장을 `Promise.all`로 **전부 기다린 뒤에야** 첫 프레임이
뜬다(localhost 447 ms). 그리고 각 PNG가 **197×197**이라 디코딩 비트맵이 186 × 197×197×4 = **28.1 MB** 상주한다.
일반 고양이는 셀 24~55px × CAT_SCALE 0.66 = **16~36 CSS px**로 그려진다. 197px가 필요한 것은 보스(최대 ~173 CSS px)뿐이다.

## 3. 로드맵

**안전선**: `scripts/`는 `main.ts`를 아무도 임포트하지 않고 `render.ts`는 `layout-probe`만 읽는다. 따라서
**render.ts·main.ts 변경은 하네스 수치에 구조적으로 도달할 수 없다**(단, `catBodySize`·`healthBarGeom`·
`gameoverGeometry` 등 probe가 부르는 export는 예외). `battle.ts`는 8축 전부가 읽으므로 **바이트 동일 증명 없이
손대면 안 된다.**

## 4. 하지 말아야 할 최적화

1. **`SIM_STEP_MS`(100) 변경, dt 가변화, 배틀 루프 상한 조정** — 판정 자체가 바뀐다. 배속은 `main.ts`의 실시간
   dt에만 곱한다는 현재 분리를 유지할 것.
2. **`actors` 정렬 제거나 `pickTarget`의 uid 타이브레이크 제거** — 동시 행동 순서가 비결정적이 되어 같은 시드가
   다른 런이 된다.
3. **`Math.hypot` → 근사 역제곱근류** — 부동소수 결과가 달라지는 순간 그 뒤가 전부 다른 런이다. C2처럼 **비교만**
   바꾸는 것과 구분할 것.
4. **`bodies()`의 `side` 필터 제거** — 적 소환수가 아군으로 세어진다(불변식 검사가 300판에서 11,417번 잡았던 경로).
5. **하네스 병렬화 시 워커에서 집계** — "정책 사본" 함정의 재발이다. 워커는 런당 원시값만 돌려주고 집계 코드는 한 벌만 둘 것.
6. **RUNS 축소로 measure-all 단축** — 잡음 바닥(지도 0.7~1.5, 배치 0.6~1.2, 유물 2.5~3.4)이 기준 여유만 하다.
7. **렌더를 OffscreenCanvas/워커로 이전** — 프레임이 1.8 ms인데 입력 지연과 복잡도만 늘어난다.
8. **`Cat`을 typed array/객체 풀로 재작성** — 이득 16 µs, 대가는 battle.ts 전면 재작성.
9. **첫 프레임을 앞당기려고 스프라이트 로딩을 통째로 비동기화** — 폴백 도형이 보이는 화면이 심사 스크린샷에 남는다.
   B1으로 요청을 1개로 줄이는 쪽이 정답이다.

---

**정리.** 런타임 병목은 전부 `render.ts`이고 `stepBattle`은 렌더의 1/100이다(16 µs vs 1,800 µs). 즉시 항목
5개(A1~A5)는 하네스가 읽지 않는 파일만 건드려 **결과 불변이 구조적으로 보장**되며 전투 −17%·지도 −60%를 낸다.
하네스 20분은 relics 60.6%+map 20.6%가 만들고, 순서 반전 테스트로 런 독립성이 실측 확인됐으므로 **시드 블록
병렬화가 결과를 바꾸지 않고 4~6분으로 줄인다** — 단 집계 코드는 한 벌로 유지해야 한다. 적재 쪽 진짜 위험은
370 KB 전송량이 아니라 **28.1 MB 디코딩 비트맵과 186개 블로킹 요청**이며, 아틀라스화 + 일반 고양이 64px화로
둘 다 사라진다.
