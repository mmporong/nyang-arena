## 2. 개선·심화 — 무엇을 넓히고, 파고, 접을까

리뷰 브리프 §6의 7개 질문에 외부 레퍼런스를 붙여 답한다. 원칙은 레포의 것을 그대로 따른다: 새 기능보다 **삭제·결합·측정 가능한 작은 변형** 먼저, 채택 시 기각 실험 동반.

### 2.1 판정: "파기" 우선, "넓히기"는 재진입 축 하나만

깊은 축 셋(유물·구매·개입)은 이미 장르 평균 이상이다. Slay the Spire·Balatro가 보여준 것은 축의 개수가 아니라 **한 축 안에서 선택지가 서로를 참조하게 만드는 것**(유물↔로스터↔다음 보스)이다. 넷째 축을 새로 파는 비용보다, 얕은 둘(배치·지도)을 깊은 축에 **종속시키거나** 화면에서 **빼는** 편이 싸다.

### 2.3 레이드 3부작(raid-design.md) 평가

**방향은 옳다.** 가장 깊은 축(개입)과 가장 큰 긴장(보스)을 콘텐츠 확장의 기둥으로 삼았고, 중앙값 플레이어가 스테이지 3 초입에서 죽는다는 수치와 3부작이 맞물린다. 그러나 **N1~N5 신규 메커니즘보다 먼저 할 것은 예고 가독성 사람 실험**이다 — 개입 축이 "색 읽고 키 고르기"에서 "버튼 하나"로 바뀐 뒤 첫 보스 +9.4%p → +0.7%p로 무너진 기록(ai-tech §1.2 ①)이 있다. 메커니즘을 늘리면 1.2초 예고 안에 읽을 것이 늘어난다. **N1(성장형 장판)·N2(체력 공유 두 보스)만 먼저**, N3~N5는 3부작 뼈대 후.

## 3. 재미 — 긴장이 어디 있고 어디 없나

메타 진행 원칙의 외부 근거: 영구 스탯 업은 숙련 감각을 희석하고([medium](https://medium.com/@jannihilator/im-better-than-my-stats-5e19fb38ac35)), 선택지 해금·Ascension은 수명 연장 표준([bugnet](https://bugnet.io/blog/how-to-design-a-roguelite-meta-progression)) — 레포의 "파워 해금 금지" 직감은 맞다. 일일 시드·챌린지 모디파이어의 리텐션 정량 자료는 미확인.

**차별점 한 줄은 이미 있다 — "예고 여섯, 개입 둘".** 이 문장을 게임 첫 화면·스토어 문구·포털 설명 첫 줄에 똑같이 써라. LLM 시너지 생성은 *개발 스토리*로는 강하지만 *플레이어 훅*으로는 약하다(§4.4).

### 4.5 AI 활용 공시 — 리스크와 포지셔닝

**Steam 2026.1.16 개정**: "플레이어 대면 AI 콘텐츠"만 공개 의무, 내부 개발 도구는 면제. [80.lv](https://80.lv/articles/steam-has-clarified-its-rules-on-the-use-of-ai-in-video-games) — 냥 아레나는 **LLM 시너지 규칙(플레이어 대면 텍스트·수치)**과 **Lyria BGM**이 공개 대상이 될 가능성이 높다. AI 공개 게임은 유사작 대비 리뷰 수 약 53% 적고 매출 40~60% 하락 추정([itechpost](https://www.itechpost.com/articles/236494/20260629/new-game-development-research-reveals-ai-impact-game-developers-steam-disclosure-concerns.htm)), 2025 출시작 20%+가 생성형 AI 사용([tech-insider](https://tech-insider.org/steam-ai-disclosure-2026/)).  
**처방:** ① 픽셀아트는 "자체 제작"을 전면에(이미 사실) ② 시너지는 "LLM이 후보를 내고 검증기·시뮬이 채택" 서사로 — 공시하되 *AI가 만든 게임*이 아니라 *측정으로 걸러낸 게임*으로 포지셔닝 ③ Steam 단계에서 BGM을 직접 제작/라이선스 곡으로 교체할지 비용 비교.

r-design 에이전트 보조 판정: "풀에서 3개 뽑기"는 플레이어에게 수작업 시너지와 구분 불가 → 현재 LLM은 **제작 효율 도구이지 플레이어 체감 차별화가 아니다**. 학계 권장(좁은 서브프롬프트 분해 + 사후 검증 + 탐색 하이브리드, [arXiv 2404.08706](https://arxiv.org/abs/2404.08706))과는 일치.

| **④ 모바일** (Capacitor 래핑) | 포털 대응이 끝나면 이식 비용이 작다. 고양이 테마는 모바일 캐주얼에서 가장 강하다. | [M2~M3] |
| **⑤ 코스메틱** | 색조 파이프라인이 있어 원가 낮음. 단, 서버 없는 웹에서는 결제 불가 → Steam/모바일에서만. | [③④ 종속] |

## 5. 실행 순서 — 지금 / 실험 후 / 보류

- **지금 (1~2주)** — **문서·지표 정합성 + 재진입 고리** metrics 재생성·숫자 통일 → 부검 화면 "다음 판" 버튼 3개(일일 시드 / 도전+1 / 같은 시드) → localStorage 도감·기록.

- **실험 1** — **지도: 제약형 경로** 가설 "경로가 상점 유무·보스 교체를 가르면 격차 ≥1.5". A/B 시드 1~300, 홀드아웃 301~600. 기각 시 지도 화면 삭제.

- **실험 2** — **배치: 인접 보너스 1종** placement-space 측정 방식 수정 후 격차 ≥1.0. 가드레일: 중앙값 ±1, 보스 통과율 −3%p 이내.

- **실험 3** — **취약 창 자원화** 콤보 이월. 통과율 기여 ≥+6%p 또는 유물 선택 분포 변화. 둘 다 아니면 연출로 확정.

- **M1 (+2개월)** — **모바일 터치·세로 레이아웃 + 영문화 + 포털 SDK 통합(비활성)** — 포털 제출·광고 스위치는 GCON 사업종료(2026.11) 이후 에 켠다(미출시 요건). 그 전엔 무료 웹·itch 데모로 플레이 볼륨·피드백만 모은다.

- **2026.12~** — **Poki/CrazyGames 제출 + 인터스티셜 1슬롯(판 사이)** + Steam 페이지 공개(위시리스트 수집 시작, 출시는 M4).

- **M2~M3** — **레이드 3부작** 예고 가독성 사람 실험 먼저 → N1·N2 → 스테이지 1~3. 콘텐츠 2배(품종·유물·보스).

- **보류** —  런타임 LLM, 리더보드, PvP, 리워드 광고, 영구 파워 해금 — 레포의 제외 확정 유지.
