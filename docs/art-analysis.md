# 냥 아레나 비주얼 분석 — 트랙 A

기준: `docs/art-brief.md`, `docs/shots/01-map.png`~`08-stage1-ember.png`, 현재 `main`의
Canvas 2D 렌더 코드. 이 문서는 새 그림을 상상한 목업이 아니라 **지금 있는 화면과 코드가 무엇을
이미 해결했고, 무엇이 아직 플레이 판단을 방해하는지**를 가른 기록이다.

## 1. 판정

현재 화면은 이미 “한밤의 고양이 다방 결투장”이라는 톤, 저채도 정체성 색, 고채도 신호 3색,
색맹 대응 형태 문법을 갖췄다. 부족한 것은 효과의 양이 아니라 **우선순위와 시간성**이다.

1. 예고는 색과 형태가 맞지만, 발동까지 남은 시간이 정지 화면처럼 읽힌다. 동시에 타격 숫자가
   중심부에 남아 가장 중요한 신호를 가린다.
2. 보스는 크기와 전용 체력바로 “강한 적”이지만, 전투에 들어오는 첫 0.5초가 일반 전투와 같아
   “사건의 시작”은 약하다.
3. 구매·레벨업·보스 처치·부검은 이미 전용 피드백이 있다. 새 효과를 겹치기보다 접근성 정책과
   등장/퇴장 리듬을 한 규칙으로 묶는 편이 효과가 크다.

따라서 트랙 A 구현은 `render.ts` 안에서 다음 네 가지로 제한한다.

- 예고 외곽에 남은 시간을 직접 보여 주는 카운트다운 표시
- 예고가 살아 있는 동안 일반 데미지 팝을 감쇠해 중앙 과밀 완화
- 보스/저격수 첫 등장 때 전장만 짧게 강조하는 카메라 스테이징
- `prefers-reduced-motion`에서 흔들림·이동·맥동·파티클을 줄이는 공통 정책

전투 시뮬레이션을 멈추는 히트스톱은 넣지 않는다. 1.2초 예고를 읽고 개입하는 게임에서 판정을
정지시키거나 화면만 멈추면 보이는 시간과 실제 시간이 갈라진다. 무게는 기존 타격 플래시·벡터 링과
보스 처치 흔들림으로 표현한다.

## 2. 현재 구현 — 다시 만들지 않을 것

| 영역 | 현재 증거 | 판정 |
|---|---|---|
| 신호 팔레트 | `theme.ts`의 `danger`·`gather`·`vuln`; 직업·진영은 저채도 | 유지 |
| 예고 형태 | `drawOneTelegraph`: 위험 해칭, 집합 동심원, 취약 고리 | 시간 표시만 보강 |
| 타격 VFX | `fxs`를 저해상도 버퍼에 그리는 ring/slash/beam/streak/burst 등 | 유지 |
| 데미지 숫자 | `drawPops`: 최대 네 단계로 겹침 회피 | 예고 중만 감쇠 |
| 상점 피드백 | `buyWithFx` → `spawnBuyTween`, 도착/레벨업 FX, 생선 롤업 | reduced-motion만 보강 |
| 보스 위계 | 전용 체력 배너, 6개 문턱, chip trail, 페이즈 전환 FX | 등장 첫 박자만 보강 |
| 승패 리듬 | 보스 처치 FX·흔들림, 전환 막, 부검과 재진입 3버튼 | 유지, 접근성만 통일 |
| 성능 | 격자·배경 캐시, FX 저해상도 버퍼, 파티클 520개 상한, 숨김 탭 rAF 정지 | 예산 유지 |

## 3. 화면별 진단

### P0 — 판단을 직접 바꾸는 화면

#### `04-boss-avoid.png`

- 위험 분홍과 사선 해칭은 색 없이도 “나가라”로 갈린다.
- 위험 원, 보스, 체력바, 데미지 숫자가 중앙에 겹친다.
- 채움과 선 굵기가 변하지만 남은 시간이 외곽에 독립된 정보로 보이지 않는다.

#### `05-boss-gather.png`

- 청록 동심원은 위험 해칭과 확실히 다르며 “모여라”는 방향성이 있다.
- 타격 효과와 숫자가 동심원 중심을 덮어 입력 타이밍보다 전투 결과가 먼저 보인다.

#### `06-boss-vulnerable.png`

- 금빛 고리와 `할퀴기!` 버튼의 결합은 세 신호 중 가장 직접적이다.
- 취약 고리는 이미 남은 시간을 원호로 보여 준다. 새 색이나 채움은 불필요하다.
- 숫자 누적만 낮추면 고리와 보스 실루엣이 더 잘 남는다.

### P1 — 사건과 재진입 리듬

#### `02-shop.png`

- 카드·가격·보유 생선·CTA의 위계는 안정적이다.
- 구매 직후 장면은 없지만 코드에는 카드→보드 트윈, 도착 링, 생선 롤업이 이미 있다.
- 새 피드백보다 이동 애니메이션을 줄여야 하는 사용자에게 같은 정보가 남도록 해야 한다.

#### `07-gameover.png`

- 도달 웨이브, 패인, 예고 성적, 팀, 최고 기록, 재진입 3갈래가 하나의 부검으로 묶였다.
- 정적 캡처는 정보 구조를 보여 주지만, 진입 순간의 감정적 마침표는 확인할 수 없다.
- 보스 처치 흔들림과 전환 막이 이미 승리 리듬을 담당하므로 부검에 추가 파티클을 얹지 않는다.

#### `08-stage1-ember.png`

- 밤·불씨·산 실루엣은 세계관을 가장 강하게 전달한다.
- 배경 불씨와 전투 신호가 같은 화면에 놓이므로 불씨는 저채도·저빈도를 유지해야 한다.
- 중앙 전환 문구는 수명이 끝나면 완전히 사라져야 하며 reduced-motion에서도 화면을 오래 막지 않아야 한다.

### P2 — 보조 정보

#### `01-map.png`

- 경로 구조와 선택 노드는 읽힌다. 정예 노드의 붉은 발톱은 가벼운 위협을 준다.
- 지도 깊이는 측정에서 기각됐으므로 별도 파티클·대형 배너를 추가하지 않는다.

#### `03-prepare.png`

- 시너지와 `싸우러 가기` CTA가 준비의 목적을 전달한다.
- 전투 시작 뒤 보스가 등장할 때만 전장 강조를 주고, 준비 화면 자체는 조용하게 둔다.

## 4. 우선순위와 성공 기준

| 우선순위 | 변경 | 성공 기준 |
|---|---|---|
| P0 | 예고 외곽 카운트다운 | 채움이 중심을 더 가리지 않고, 0→발동 진행이 외곽에서 읽힘 |
| P0 | 예고 중 숫자 감쇠 | 일반 숫자는 물러나고 회복·치명·회피 정보는 식별 가능 |
| P1 | 보스 등장 스테이징 | HUD·버튼은 고정, 전장만 0.5~0.7초 강조, 입력/판정 불변 |
| P1 | reduced-motion | 카메라 흔들림·줌·맥동·파티클·장거리 구매 이동 감소 |
| P2 | 정예 | 기존 미니보스 배너와 짧은 등장 강조만 사용, 지도 효과 추가 없음 |

## 5. 하드 제약 감사

- 수정 대상은 시각 파일과 문서뿐이다. 밸런스·전투·런·지도 규칙은 바꾸지 않는다.
- 새 패키지, 원격 리소스, 런타임 네트워크 요청을 추가하지 않는다.
- 판 위 고채도는 기존 위험/집합/취약 세 색만 사용한다.
- 숨김 탭 정지는 `main.ts`의 기존 `document.hidden` rAF 중단과 복귀 시 `last = 0` 계약을 유지한다.
- 각 커밋은 `npm run verify`의 6축 원시 출력과 정규화한 `metrics` 게임 수치 SHA-256을 부모와 비교한다.
  `generatedFrom.commit`, dirty/reproducible 플래그, VFX 번들 크기는 게임 수치가 아니므로 비교에서 분리하고,
  `bundleBytes`는 별도 성능 증거로 기록한다.

## 6. 증거 공백

- 기존 캡처에는 보스/저격수 등장 첫 프레임, 구매 직후, reduced-motion 상태가 없다.
- 트랙 A 구현 뒤 동일 상태를 새 캡처로 보강한다.
- 승리 전용 화면은 없고 보스 처치→지도 복귀가 승리 리듬이다. 별도 승리 모달을 만들지 않는다.
