### 게임 썸네일

```text

```

현재 파일은 PNG, `1280×720`, 약 `219KB`로 공식 형식·크기 조건을 충족한다. 다만
보스 전투를 보여 주는 이전 구성이어서 “내가 다음 보스 규칙을 고른다”는 악몽 계약의
첫 선택을 직접 보여 주지는 않는다. 기술적으로 제출 가능하지만 Presentation 축에는
계약 선택 화면 기반 썸네일이 더 강하다.

### 데모 영상 링크 — 선택 가산점

현재 저장소 영상 `docs/gameplay.mp4`는 `52.672초`, `1280×720`, H.264+AAC로 3분
조건을 충족한다. 그러나 GitHub Pages의 `/gameplay.mp4`와 `/docs/gameplay.mp4`는
현재 404이며, raw GitHub 주소는 `application/octet-stream` 다운로드 응답이다.
따라서 폼에는 재생 화면이 바로 열리는 공개 스트리밍 URL을 확보하기 전까지 임시
주소를 넣지 않는다.

영상에서 사용할 결정적 공유 코드:

```text
NA1-93CI-split_night
```
