## 챌린지 기간(08/04~) 개발 내용 — 명기용

프로젝트의 첫 커밋은 한국시간 08/05이며 챌린지 기간의 개발 이력은 공개 저장소에서 전부
검증할 수 있다(github.com/mmporong/nyang-arena). 커밋·파일·줄 수는 계속 바뀌는
수치라 제출 문안에는 넣지 않는다.

주요 신규 개발:
- 소환 시스템 + 다섯 번째 직업 소환사, 품종 8→15종 (색조 파이프라인)
- 원버튼 개입(산개/집결/할퀴기)으로 개편, 회피 실효성 39%→100% 수정
- 보스 예고 재설계 — 판 고정 예고(화톳불·땅울림·발구르기), 보스별 최적
  대형 분화 (실측 검증)
- 보스전 근본 개선 13종 — 예고 잔존 버그, 판정-그림 기하 일치(몸 반경 패딩),
  순간이동 3단 연출, 처치 연출·보상, 타겟 표시, 목표 난이도 3단(실측 라벨)
- 스테이지 우두머리 위상 (지도 왕관·칭호·보상 차등)
- 구매·배치 화면 통합, 상점 슬롯·재화 연출 (5개 게임 관례 조사 기반)
- 악몽 세계관 전환 (적 명단 분리, 지도 상향 흐름, 어투 통일)
- 측정 인프라 — 검증 6축, 불변식 ~50만 스텝, 발동 시점 실효성 검사,
  난이도 층 실측 (npm run tiers)
