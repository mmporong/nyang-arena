## Codex 활용 — 정직하게 채우는 계획

이 게임은 지금까지 Claude Code로 개발했고 문서에 그렇게 명시돼 있다
(NAN 제출 문서). **행사는 "게임을 만드는 과정에 Codex를 활용해야 합니다"가
요건**이므로, 참가하려면 지금부터 실제 개발을 Codex로 진행해야 한다 —
거짓 기재는 하지 않는다.

남은 기간(~08/26)의 실개발 후보 (진행 중인 보스 고도화의 다음 단계들):

1. **페이즈 전환·취약 창 연출** (US-104) — render 레이어 작업, 범위가 명확해
   Codex 세션에 통째로 맡기기 좋다
2. **리뷰 패스** — omc의 `--critic=codex`로 완료 리뷰를 Codex가 수행
   (도구 협업의 실증)
3. 신규 기능 1개를 Codex 주도로 (예: 유물 도감·부검 화면 확장)

기록 방식: Codex 세션 로그·프롬프트·해당 커밋 해시를 모아 "Codex 활용 과정
설명"에 사실대로 쓴다 — "Claude Code와 Codex를 함께 썼고, X·Y·Z는 Codex가
만들었다"가 문안의 뼈대.

## 챌린지 기간(08/04~) 개발 내용 — 명기용

커밋 183개 · 1,210파일 변경 누적 · +27,846 / −4,796 줄. 전부 공개 저장소
이력으로 검증 가능 (github.com/mmporong/nyang-arena).

주요 신규 개발:
- 소환 시스템 + 다섯 번째 직업 소환사, 품종 8→15종 (색조 파이프라인)
- 원버튼 개입(산개/집결/할퀴기)으로 개편, 회피 실효성 39%→100% 수정
- 보스 예고 재설계 — 판 고정 예고(화톳불·땅울림·발구르기), 보스별 최적
  대형 분화 (실측 검증)
- 보스전 근본 개선 13종 — 예고 잔존 버그, 판정-그림 기하 일치(몸 반경 패딩),
  순간이동 3단 연출, 처치 연출·보상, 타겟 표시, 목표 난이도 3단(실측 라벨)
- 스테이지 우두머리 위상 (지도 왕관·칭호·보상 차등)
- 구매·배치 화면 통합, 상점 슬롯·재화 연출 (5개 게임 관례 조사 기반)
- 악몽 세계관 전환 (적 명단 분리, 지도 상향 흐름, 어투 통일)
- 측정 인프라 — 결정 축 7관문, 불변식 ~50만 스텝, 발동 시점 실효성 검사,
  난이도 층 실측 (npm run tiers)
