# 레이드 3부작 설계 — 확장팩을 스테이지로

> WoW 클래식~리치왕 레이드 리서치(2026-08-20, 출처는 리서치 원문)를 냥 아레나
> 문법으로 번역한 설계 문서. 아직 구현 계획이지 확정 사양이 아니다.

## 왜 3부작인가 — 수치가 허락한다

도달 웨이브 중앙값이 15다. 한 스테이지가 6걸음이므로 **중앙값 플레이어가
스테이지 3 초입에서 죽는다** — "클래식 → 불성 → 리치왕" 3부작이 실제 플레이
범위와 정확히 겹친다. 잘하는 판(p75 = 24)이 리치왕을 잡고 끝나는 그림.

```
스테이지 1  화산심장부   불 · 주황/용암     입문 — 기존 문법 그대로
스테이지 2  낙스라마스   역병 · 보라/초록   중급 — 산개·집결 판단 심화
스테이지 3  얼음왕관     얼음 · 파랑/보라   최종 — 신규 메커니즘 둘
(4+)       순환 재시작 (배율만 계속 상승 — 지금 구조 유지)
```

불성을 스테이지에서 뺀 이유: 불성의 상징 기믹(쌍둥이 황제·큐브 인터럽트)은
전부 **신규 시스템**을 요구해서 3부작 뼈대를 먼저 세운 뒤의 확장 재료로
아끼는 것이 싸다. 낙스라마스가 클래식의 끝이자 리치왕 서사의 시작이라
징검다리로도 옳다.

## 스테이지별 설계

### 스테이지 1 — 화산심장부 (불)

| 슬롯 | 콘셉트 | 냥 아레나 번역 | 난도 |
|---|---|---|---|
| 잔몹 팔레트 | 불정령·화염사냥개 | 악몽 고양이 주황/적 색조, rush 위주 | 낮음 |
| 웨이브 성격 | 코어하운드 팩 | mixed → rush → snipe(라바팩) → mixed | 낮음 |
| 중간보스 | 마그마다르 | 기존 무쇠발톱 리스킨 + 공포(circle avoid)·라바밤(line) | 낮음 |
| 우두머리 | **라그나로스** | 2페이즈: 지상(stomp·quake 근접 압박) ↔ 잠수(호위 잔몹 웨이브 — "TOO SOON!") | 중간 |

라그나로스 잠수 페이즈 = **우두머리 2페이즈 슬롯(구현 완료)** + 페이즈 2를
"패턴 교체"가 아니라 "보스 무적 + 잔몹 웨이브"로 두는 변형. 이미 blink의
무적 처리(gone)가 있어서 그 경로를 재사용할 수 있다.

### 스테이지 2 — 낙스라마스 (역병)

| 슬롯 | 콘셉트 | 냥 아레나 번역 | 난도 |
|---|---|---|---|
| 잔몹 팔레트 | 구울·거미·산성 안개 | 보라/초록 색조, 거미(도적형)·구울(전사형) | 낮음 |
| 웨이브 성격 | 거미지구·역병지구 | mixed → snipe(거미 저격) → rush(구울 물량) → mixed | 낮음 |
| 중간보스 | **헤이건** — 안전지대 춤 | **행 단위 순차 스윕**(line avoid가 행을 차례로 점멸) — 5×5에 자연스럽고 밈 계승 | 중간 |
| 우두머리 | **사피론 → 켈투자드** 중 택1 | 사피론: 얼음 블록 뒤 숨기(시간차 안전지대) / 켈투자드: 개인 지연폭발 + 균열 | 중간~높음 |

**타디우스 극성(+/−)**은 조작 확장(아래)과 세트로 여기 들어올 후보 —
보드 좌/우에 gather와 avoid가 동시에 떠서 "어느 쪽으로 갈지"를 가른다.

### 스테이지 3 — 얼음왕관 (리치왕)

| 슬롯 | 콘셉트 | 냥 아레나 번역 | 난도 |
|---|---|---|---|
| 잔몹 팔레트 | 구울(하급)·발키르(정예) | 얼음 파랑(rush) / 죽음 보라(snipe) 이원 | 낮음 |
| 웨이브 성격 | ICC 진격 | rush(구울) → snipe(발키르) → mixed → mixed | 낮음 |
| 중간보스 | **신드라고사** | cone(서리 숨결) + 표식 후 산개 — 리치왕의 "표식 후 집결"을 미리 가르침 | 중간 |
| 우두머리 | **리치왕** | 3페이즈 + 신규 메커니즘 둘 (아래) | 높음 |

리치왕 페이즈 구성(리서치 번역):
1. P1: 발키르(circle gather — 집결 실패한 표식냥은 판 밖으로 던져짐)
2. 소강: 서리한 겨울 = **quake 그대로** + 분노한 영혼 잔몹
3. P2: **파멸(Defile)** + 소울리퍼(구원 연타 — 취약 창 슬롯의 의미 반전)
4. 10%: **"지는 것이 연출"** — 2~3초 강제 빈사 → 구원 플래시 → 마지막 취약 창
   연타 마무리. 게임 전체에서 단 한 번.

## 신규 메커니즘 로드맵 (구현 순)

| # | 메커니즘 | 원본 | 최소 확장 | 난도 |
|---|---|---|---|---|
| N1 | **성장형 장판** | 파멸(Defile) | circle avoid를 상주형으로: 반경·틱·소멸 타이머 3개 상태값. 렌더·판정 재사용 | 낮음~중간 |
| N2 | **체력 공유 두 보스** | 피의 왕자 / 쌍둥이 황제 | 체력바 1개 유지, "활성 대상" 플래그가 순환. 비활성은 무적. 보스별 예고 계열 분리 | 낮음~중간 |
| N3 | 이동형 낙인 | 리빙 밤 / 소울리퍼 | 예고 앵커를 보스·판이 아니라 **아군 유닛**에 붙임 | 중간 |
| N4 | 순차 스윕 | 헤이건 | line avoid가 행 0→4를 차례로 점멸 | 중간 |
| N5 | 극성 분할 | 타디우스 | 보드 좌/우에 gather·avoid 동시 표시 + 주기 리롤 | 중간 |
| — | 독립 체력 다중 보스 | 강철 회합 | **유보** — 개입 2회 문법과 충돌, 하드모드 후보 | 높음 |

**원거리형 보스**: 쌍둥이 황제의 물리/마법 면역 축을 N2에 얹으면 "근접만
박히는 보스 / 원거리만 박히는 보스"가 된다 — 직업 명령(아래 C3)과 세트.

## 조작 확장 — "버튼이 늘어도 손이 빨라질 필요는 없다"

기존 논지(조작이 아니라 결정을 늘린다, GDC TFT 원칙)를 지키는 확장 기준:
**반응속도 요구 금지, 1.2초 예고 안에서 고르는 판단만 추가.**

| # | 조작 | 세트가 되는 기믹 | 여는 결정 |
|---|---|---|---|
| C1 | **산개/집결 수동 선택** (버튼이 두 갈래로: 짧게=산개, 길게=집결 or 버튼 2개) | 타디우스 극성(N5) — 자동 판단이 불가능한 "반반 장판" | 예고 읽기가 실력이 됨 |
| C2 | **앞라인 전진/후퇴** | 파멸(N1) 빠지기, 라그나로스 stomp 거리 조절 | 배치가 전투 중 결정이 됨 — 죽은 배치 축(0.8)의 부활 후보 |
| C3 | **직업 단위 명령** (근접만/원거리만) | 쌍둥이 황제(N2 + 면역 축) — 근접은 A로, 원거리는 B로 | 구성(무엇을 샀나)이 개입과 연결됨 |
| — | 유닛 개별 드래그 (실시간) | — | **탈락** — 실행 난도라 원칙 위반 |

권장 도입 순서: **C1 → C2 → C3.** C1은 기존 버튼의 의미 분화라 UI 비용이
최소이고, N5(타디우스)와 함께 스테이지 2에서 데뷔하면 "새 스테이지 = 새
읽기"가 된다. C3는 N2 없이는 의미가 없으므로 마지막.

## 구현 웨이브 (제안)

```
웨이브 1  스테이지 테마 시스템 — 스테이지별 잔몹 색조·웨이브 성격 배치·팔레트
          + 스테이지 1 (화산심장부) 완성. 신규 메커니즘 0개, 리스킨과 데이터 중심
웨이브 2  N1 성장형 장판 + N4 순차 스윕 + 스테이지 2 (낙스라마스)
          + C1 산개/집결 수동화 + N5 극성
웨이브 3  스테이지 3 (리치왕) — 신드라고사·리치왕 3페이즈·"지는 것이 연출"
웨이브 4  N2 체력 공유 두 보스 + C3 직업 명령 (별도 스테이지 또는 히든 보스)
```

각 웨이브 끝마다 관문(verify) 재측정 — 특히 보스 통과율과 개입 축.

## 이미 있는 것 (오늘 구현분이 이 설계의 기초 공사)

- 우두머리 2페이즈 슬롯 (US-101) — 라그나로스·리치왕이 그대로 탄다
- 취약 창×예고 겹침 (US-102) — 소울리퍼 "구원 연타"의 전제
- gather 조기 학습 (US-103) — 발키르 집결 기믹의 훈련장
- 판 고정 예고 hearth/quake — 서리한 겨울·호디르 화톳불의 기하
