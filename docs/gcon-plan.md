경기게임오디션 제21회 · 일반부문 · 2026-08

**https://mmporong.github.io/nyang-arena/** — 클릭하면 바로 실행됩니다. 설치·로그인·결제가 없습니다.

> 이 문서는 **시장성**과 **출시 가능성**을 다룹니다. 게임이 왜 재미있는지는 별도

**사업적으로 중요한 것은 이 셋입니다.**

1. **설치 전환 손실이 0입니다.** 광고를 눌러 게임이 시작되기까지 다운로드·설치·
   로그인·튜토리얼이 하나도 없습니다. 40KB는 배너 이미지 몇 장 크기입니다
2. **운영비가 거의 고정입니다.** 서버도 계정도 결제 백엔드도 없는 정적 배포라,
   유저가 늘어도 늘어나는 비용이 CDN 트래픽뿐입니다
3. **완성돼 있습니다.** 기획서가 아니라 지금 플레이할 수 있는 빌드가 있고,
   그 위에 자동화된 품질 검사가 돌고 있습니다

## 2. 무엇을 만들었나

### 핵심 루프

```
길 고르기 → 이번 상대 확인 → 사고 놓기 → 전투(보스전엔 개입) → 다시 길
```

지도에서 다음 걸음을 고르는 **순간 이번에 싸울 상대가 정해지고 화면에 뜹니다.**
상점은 그다음입니다. 멀리서 쏘는 것들이 온다는 걸 보고 근접을 사거나, 보스가
뜨는 걸 보고 앞줄을 두껍게 할 수 있습니다. 같은 카드가 판마다 다른 값을 갖는
이유입니다.

### 차별점 — 전투 단계의 결정 노드

오토배틀러가 전투 조작을 없앤 것은 실수가 아니라 의도된 설계입니다. Riot은
GDC 2020에서 TFT의 원칙을 **"어려운 선택이지, 어려운 실행이 아니다"**로
정리했습니다. 오토체스에 있던 빠른 조작을 일부러 걷어냈는데, 그것이 정보를
빨리 처리하지 못하는 플레이어를 처벌하기 때문이었습니다.

그 판단은 옳았고, 우리도 되돌리지 않습니다.

**다만 그 결과로 생긴 빈자리가 하나 있습니다.** 이 장르의 결정은 전부 상점
단계에 몰려 있고, 전투는 결과를 통보하는 구간입니다. 가장 긴장되는 순간인
보스전에 플레이어가 할 일이 없습니다.

냥 아레나는 거기에 결정을 하나 심습니다. 보스는 체력이 깎일 때마다 장판을
예고합니다 — 여섯 번. 플레이어가 가진 개입은 **두 번**입니다. 앞을 막으면
뒤가 비고, 아끼면 지금 맞습니다.

**손이 빨라도 이기지 않습니다.** 무엇을 할지는 게임이 정하고(붉으면 흩어지고,
청록이면 모이고, 금빛이면 몰아칩니다), 언제 쓸지만 플레이어가 정합니다.
실행 난이도를 요구하지 않으므로 위의 GDC 원칙을 거스르지 않고, 오히려 그
연장선입니다.

## 3. 시장

### 3.1 이 조합이 검증돼 있다는 근거

자동 전투에 개입을 넣는 설계는 상업적으로 이미 확인됐습니다.

| 사례 | 무엇을 했나 | 결과 |
|---|---|---|
| **AFK Journey** | 자동 전투 + 궁극기 수동 발동 | 누적 매출 1억 5천만 달러 이상 |
| **Vivid Knight** | 전투 중 주기적으로 카드 한 장 사용 | "자동인데 매우 전술적"이라는 평 |
| **Vampire Survivors** | 공격을 전부 자동화하고 이동만 남김 | BAFTA 올해의 게임 |

**공통점은 "조작을 줄이되 결정은 남긴다"입니다.** 셋 다 실행 난이도를 낮추고도
플레이어를 관객으로 만들지 않았습니다.

### 3.2 그런데 비어 있는 자리

다만 **보스전에만, 자원을 제한해, 예고를 읽고 배분하는** 조합은 오토배틀러에서
선례를 찾지 못했습니다. MMO 레이드의 장판 문법을 오토배틀러에 옮긴 셈입니다.

위 사례들은 개입이 **상시**입니다(쿨다운마다 쓴다). 냥 아레나는 개입이 **희소**
합니다(여섯 중 둘). 상시 개입은 "언제 눌러도 이득"이라 결국 반복 조작이 되지만,
희소 개입은 **포기가 강제**되므로 매번 판단이 생깁니다.

### 3.3 채널 — 웹 즉시 실행

이 게임의 가장 큰 사업적 자산은 장르가 아니라 **배포 형태**입니다.

| | 설치형 모바일/PC | 냥 아레나 |
|---|---|---|
| 광고 클릭 → 플레이 | 스토어 이동 → 다운로드 → 설치 → 실행 → 로그인 | **즉시** |
| 이탈 지점 | 4~5곳 | 0곳 |
| 최초 전송량 | 수십~수백 MB | **gzip 약 40KB** (+ 스프라이트) |
| 플랫폼 수수료 | 30% | 0% (자체 배포 시) |
| 서버 비용 | 계정·세이브·매칭 | **없음** (전부 클라이언트) |

40KB는 **플레이어블 광고 소재로 그대로 쓸 수 있는 크기**입니다. 별도 데모 빌드를
만들 필요가 없습니다 — 광고 안에서 돌아가는 것이 곧 본편입니다.

### 3.4 타깃

**1차** — 오토배틀러·로그라이크 경험자(TFT·슬레이 더 스파이어·뱀서라이크).
장르 문법을 아는 사람에게는 "예고 여섯, 개입 둘" 한 줄이면 설명이 끝납니다.

**2차** — 짧은 세션을 찾는 캐주얼 플레이어. 한 판이 2분 안팎이고 진행 상황을
저장할 필요가 없습니다.

**3차** — 고양이 IP 선호층. 아트가 픽셀 고양이라 장르 진입장벽을 낮춥니다.

## 4. 수익 모델 (제안)

> **〔확인 필요〕** 아래는 게임 구조에서 도출한 제안이며 확정된 사업 계획이
> 아닙니다. 실제 제출 시 대표자 확인이 필요합니다.

### 4.1 하지 않을 것부터

**확률형 뽑기와 성장 과금은 넣지 않습니다.** 이 게임의 재미는 "제한된 자원을
어디에 쓸까"이고, 과금으로 자원을 더 주면 그 결정이 사라집니다. 개입 횟수를
돈으로 파는 순간 게임의 유일한 차별점이 무너집니다.

광고 보상형(리워드 광고)도 같은 이유로 배제합니다.

### 4.2 할 것

| 단계 | 모델 | 근거 |
|---|---|---|
| **1단계** (현재) | 웹 무료 공개 | 유저 확보와 지표 수집. 비용이 거의 0이라 유지 가능 |
| **2단계** | Steam 유료 정식판 | 콘텐츠 확장(품종·보스·유물)과 메타 진행을 담은 완전판 |
| **3단계** | 코스메틱 DLC | 고양이 색조·품종 팩. **게임 밸런스에 영향 없음** |

**2단계가 주 수익원입니다.** 웹판은 무료 체험이자 마케팅 채널이고, 슬레이 더
스파이어·뱀파이어 서바이버즈가 증명한 "한 번 사면 끝" 모델을 따릅니다.

코스메틱이 성립하는 근거가 하나 더 있습니다 — **아트가 색조 변경으로 확장되게
설계돼 있습니다.** 스프라이트 하나에서 색조·채도를 바꿔 새 품종을 만드는
스크립트가 이미 파이프라인에 있습니다. 신규 코스메틱 원가가 매우 낮습니다.

## 5. 출시 가능성

이 축이 가장 강합니다. **이미 출시돼 있는 것과 다름없는 상태**이기 때문입니다.

### 5.1 지금 상태

| | |
|---|---|
| 플레이 | 브라우저에서 즉시 · 설치·로그인·결제 없음 |
| 콘텐츠 | 고양이 **15종** · 직업 **5종** · 능력 **13종**(+패시브 2) · 유물 **11종** · 보스 **4종** |
| 기술 | TypeScript + Canvas 2D · **런타임 의존성 0개** · 게임 엔진 없음 |
| 네트워크 | 실행 중 **외부 요청 0건** — 최초 로딩 뒤에는 끊겨도 돌아갑니다 |
| 배포 | GitHub Pages 정적 호스팅. CI 없이도 빌드 한 번이면 갱신 |

### 5.2 기술 리스크가 낮은 이유

**런타임 의존성이 0개입니다.** 게임 엔진도, 프레임워크도, 외부 라이브러리도
쓰지 않습니다. 이것은 취향이 아니라 리스크 관리입니다 —

- 엔진 버전 업그레이드로 빌드가 깨지는 일이 없습니다
- 서드파티 라이선스 분쟁 여지가 없습니다
- 보안 패치를 따라가야 할 의존성 트리가 없습니다
- 브라우저가 Canvas 2D를 버리지 않는 한 동작합니다

**서버가 없습니다.** 계정·세이브·매칭·결제 백엔드가 전부 없으므로 운영 장애의
표면적이 CDN 하나입니다.

### 5.3 품질을 감이 아니라 검사로 지킵니다

매 변경마다 자동 검사가 돕니다.

| 검사 | 규모 | 무엇을 보나 |
|---|---|---|
| 불변식 검사 | **486,310 스텝** | 체력이 음수가 되는지, 고양이가 판 밖에 서는지 등 |
| 밸런스 시뮬레이션 | 300~2,000판 | 도달 웨이브 분포, 웨이브 성격별 통과율 |
| 결정 축 관문 | 7개 축 | 각 결정이 실제로 결과를 가르는지 |

**이 검사들이 실제로 버그를 잡았습니다.**

- 웨이브 3에서 세 판 중 한 판이 전멸하던 문제 (400판 중 125판 → 23판)
- 적의 소환수가 우리 편으로 세어지던 버그 (11,417회 오집계)
- 되살리기 능력이 시전은 되는데 0마리를 소환하던 결함 (392회 시전 / 0 소환)

### 5.4 우리가 아직 못 푼 것

**결정 축 7개 중 6개가 기준 안에 있고, 1개가 미달입니다.** 숨기지 않고 적습니다.

| 축 | 상태 |
|---|---|
| 도달 웨이브 분포 · 구매 · 배치 · 개입 · 수입 · 유물 | 통과 |
| **지도(경로 선택)** | **미달** — 격차 0.9웨이브 (기준 1.5) |

지도 축은 진단이 끝나 있습니다. 자원이 생선 하나뿐이라 모든 경로 선택이 "더
벌까 덜 쓸까"로 수렴합니다. 보상을 더 주는 것으로는 안 풀리고 **판 구조를 바꿔야**
한다는 것까지 확인했습니다. 정식판 로드맵의 1순위 항목입니다.

**이걸 적는 이유가 있습니다.** 이 팀은 "재미있어졌다"를 감으로 말하지 않고
숫자로 재고, 기준에 못 미치면 못 미친다고 기록합니다. 위 세 버그를 잡은 것도
같은 습관에서 나왔습니다.

> **〔확인 필요〕** 일정은 인력 규모 확정 후 조정이 필요합니다.

| 시기 | 마일스톤 | 내용 |

| **M1** (+2개월) | 지도 축 해결 · 모바일 터치 대응 | 미달 축 해소, 세로 화면 레이아웃 |
