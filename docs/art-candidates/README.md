# P0 액션 포즈 이미지 생성 후보

이 폴더의 PNG는 ChatGPT/Codex 앱 내장 이미지 생성으로 만든 **아티스트 전달용 포즈
콘셉트**다. `public/sprites/`에 넣는 런타임 최종본이 아니다.

## 후보

| 파일 | 기준 이미지 | 의도 | 실측 |
|---|---|---|---|
| `01_attack-imagegen-concept.png` | `../../public/sprites/01_run.png` | 몸을 앞으로 기울이고 앞발을 짧게 뻗는 공격 키 포즈 | 1254×1254 RGBA, 실제 투명 배경 |
| `01_hit-imagegen-concept.png` | `../../public/sprites/01_idle.png` | 몸을 움츠리고 한쪽 앞발을 드는 피격 키 포즈 | 1254×1254 RGBA, 실제 투명 배경 |
| `01_attack-imagegen-concept-v2.png` | `../../public/sprites/01_idle.png` | 몸 전체를 오른쪽으로 던지고 앞발을 머리 너비 이상 뻗는 돌진 공격 | 1254×1254 RGB, 체크무늬 배경이 실제 픽셀로 포함됨 |
| `01_hit-imagegen-concept-v2.png` | `../../public/sprites/01_idle.png` | 몸통·머리·다리를 서로 다른 축으로 꺾은 왼쪽 피격 반동 | 1254×1254 RGBA, 실제 투명 배경 |

초기 두 후보는 얼굴과 정면 몸통 윤곽이 기존 포즈와 거의 같아 포즈 명세로도 차이가
부족하다. 비교·실패 기록으로만 남긴다. v2는 캐릭터를 검은 실루엣으로 보아도
`idle`·공격·피격을 구분할 수 있도록 몸통 축, 앞발 도달 거리, 머리와 골반의 상대 위치를
바꿨다.

초기 두 후보와 v2 피격 후보는 배경 추출 뒤 알파 채널은 생겼지만 반투명 외곽과 내부
그라데이션이 남아 있다. v2 공격 후보는 배경 제거 결과의 알파가 지나치게 낮아져 폐기하고
포즈 확인이 가능한 RGB 생성 원본을 남겼으므로 체크무늬까지 실제 픽셀이다. 따라서 어느
후보도 197×197로 단순 축소해 최종본으로 쓰면 안 된다.

## 앱 생성 프롬프트 요약

- 같은 턱시도 고양이의 얼굴 무늬와 기존 팔레트를 유지한다.
- v2 `attack`은 오른쪽으로 기울어진 몸통, 머리 너비 이상 뻗은 앞발, 뒤로 빠진 반대발로
  비대칭 돌진 실루엣을 만든다.
- v2 `hit`은 왼쪽으로 밀린 머리, 뒤로 젖힌 몸통, 서로 다른 높이의 네 발과 꺾인 꼬리로
  공격 포즈와 반대 방향의 반동 실루엣을 만든다.
- 요청 목표는 실제 알파 투명 배경과 단색 하드 픽셀이며, 글자·UI·이펙트·그림자는 넣지
  않는다. 생성 결과가 이 조건을 충족하지 않으면 콘셉트로만 분류한다.
- 판 위 신호색 `#FF3F6E`, `#2BE3B4`, `#FFE24A`를 넓은 면에 추가하지 않는다.

## 최종 원화 전달 조건

아티스트 또는 픽셀 편집 단계에서 아래 조건을 모두 맞춘 별도 파일을
`public/sprites/01_attack.png`, `public/sprites/01_hit.png`로 납품한다.

- 197×197 RGBA
- 알파 0 또는 255만 사용
- 같은 ID의 기존 스프라이트와 몸 중심·발 기준선 오차 ±2px
- 기존 팔레트와 픽셀 밀도 유지
- 타이트 크롭·안티앨리어싱·반투명 외곽·그라데이션 없음
