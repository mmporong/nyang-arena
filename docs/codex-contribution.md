# Codex 기여 추적표 — OpenAI Game Builder Challenge

> 목적: “AI가 많이 했다”는 모호한 주장이 아니라, 문제→Codex 산출물→거절/채택→
> 사람 결정→검증을 공개 저장소에서 따라갈 수 있게 한다.

## 기여 경계

- 기존 기반: 고양이 구매·배치·자동 전투, 기존 보스 예고, 시너지 DSL, 지도·유물,
  재도전, 기존 아트·오디오.
- 이번 Codex 핵심: 제출 방향 분석, 악몽 계약 제품 명세, 계약 DSL·검증·출고,
  첫 화면/UI/공유/보스 적용, 위험별 준비 경로, 유물 택1 드래프트, 검증 관문·제출 문서.
- 사람 결정: 게임의 근간 변경 허용, 위험·보상 범위 승인, 저품질 생성 캐릭터 전량
  폐기, 권리 불명 PNG 제거, 런타임 API를 넣지 않는 배포 전략, 최종 제출 책임.
- 하지 않는 주장: 이전 Claude/사람 코드를 Codex가 썼다고 재표기하지 않는다.

## Codex가 해결한 기술 문제

1. **신뢰 경계** — JSON을 바로 실행하지 않고 좁은 `RaidContract` 스키마와 기존
   `BossPattern` 화이트리스트를 통과한 것만 출고한다.
2. **결정성** — 계약 제안은 전투 RNG와 분리한 `(seed, bossIndex)` 스트림을 써서
   같은 조건에서 같은 세 장을 만든다.
3. **게임 적용** — 계약은 대상 보스 인덱스가 일치할 때만 패턴·후반 패턴·위험
   배율을 바꾸고, 승리할 때만 추가 생선을 준다.
4. **플레이어 이해** — 첫 화면에서 규칙·대응·위험·보상을 보여 주고 지도에서
   위험별 준비 경로를 금색 이중 고리로 표시한다.
5. **검증 정직성** — RNG 소비가 갈라지는 시드별 신탁을 짝비교로 해석하지 않는다.
   1500런 지도 독립 평균·300시드 실제 준비 전이·1800시드 × 출고 6계약 첫 두 보스 독립 실행으로
   지도 효과, 자원 전달, 계약 지배도를 따로 증명한다. 유물은 같은 직업 집중 정책의
   on/off 대조로 구매 정책 차이를 제거한다.

## 재현 명령

```powershell
cd $HOME\nyang-arena
npm ci
npm run gen:contracts
npm run contract:test
npm run contracts
npm run map
npm run verify
```

`npm run verify`는 6축 원시 출력과 종료 코드·명령·시드·HEAD/tree를
`.omx/evidence/verify-6axis/`에 남기고, `npm run metrics`는 각 로그 SHA-256과
계약 holdout·맵 통제 결과의 provenance가 현재 커밋과 일치할 때만 PASS로
`docs/generated/metrics-current.json`에 결합한다. `.omx` 로그는 로컬 실행 증거,
생성된 metrics와 Git 커밋은 공개 재현 증거다.
